# BASEERA evaluator rubric

Score each category from 1–10 and calculate the weighted total.

| Category | Weight | Passing evidence |
| --- | ---: | --- |
| Business correctness | 25% | Golden metrics, cleaning reconciliation, consistent dashboard/report/export values, explicit unavailable states. |
| Functional depth | 25% | Integrated journeys persist, recover, enforce versions, and use real calculations rather than static screens. |
| Design quality and craft | 20% | Calm executive hierarchy, coherent tokens, dense-data resilience, useful evidence rail, deliberate states. |
| Security and trust | 15% | Tenant/resource checks, protected fields, safe upload/query/export behavior, evidence provenance. |
| Arabic and accessibility | 10% | Genuine RTL/LTR, localized formatting, keyboard operation, focus, contrast, chart alternatives. |
| Operational readiness | 5% | Reproducible startup, locks, health checks, observable jobs, honest capability/status records. |

Passing threshold: **7.0/10** with no unresolved critical security or correctness defect. A polished
screenshot does not offset fabricated data, broken controls, or missing authorization.
