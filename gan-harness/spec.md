# BASEERA build harness specification

The authoritative specification is [`../PROJECT_SPEC.md`](../PROJECT_SPEC.md). Build the complete
Arabic/English enterprise analytics product described there as integrated vertical slices. The first
quality gate is the real journey from a dirty multi-sheet workbook through immutable ingestion,
profiling, reviewed cleaning, governed metrics, an executive dashboard, evidence inspection, and a
versioned report. All subsequent company, assistant, connector, forecasting, process, optimization,
simulation, administration, and operational capabilities must reuse those contracts.

Never use invented values as live results. Demo data must be deterministic, visibly fictional, and
processed through the same code paths as uploads. Unavailable providers and external systems must be
shown as configuration-blocked rather than simulated.
